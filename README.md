# Условие задачи
Садовод-робот сажает семена в лунки. Лунка считается "идеальной" для посадки, если все три измеренных параметра кислотности почвы (A, B, C) кратны трем. Запишите условие для "идеальной" лунки.
# 1. Алгоритм и блок-схема
# Алгоритм
1. Начало:
2. Объявить константы:
   - ячейки для целых чисел и даём им имена параметров почвы: A, B и C.
4. Задать исходные данные:
   - с помощью функции scanf - раскладываем числа A,B,C по ячейкам.
5. Рассчитать условия кратности:
   - Делит A на 3 и проверяет, равен ли остаток нулю (A % 3 == 0).
   - Делит B на 3 и проверяет остаток (B % 3 == 0).
   - Делит C на 3 и проверяет остаток (C % 3 == 0).
   - Если 3 числа разделить без остатка то это выражение Истина.
   - Если хотя бы 1 дало остаток то Ложь.
6. Вывести результат расчётов в текст:
   - Если там 1, на экран выводится фраза: «Лунка является ИДЕАЛЬНОЙ».
   - Если там 0, срабатывает ветка else и выводится фраза: «Лунка НЕ подходит».
7. Конец
