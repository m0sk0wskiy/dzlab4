# Условие задачи
Садовод-робот сажает семена в лунки. Лунка считается "идеальной" для посадки, если все три измеренных параметра кислотности почвы (A, B, C) кратны трем. Запишите условие для "идеальной" лунки.
# 1. Алгоритм и блок-схема
# Алгоритм
1. Начало:
2. Объявить константы:
   - ячейки для целых чисел и даём им имена параметров почвы: A, B и C.
4. Задать исходные данные:
   - с помощью функции scanf - раскладываем числа A,B,C по ячейкам.
5. Рассчитать условия кратности:
   - Делит A на 3 и проверяет, равен ли остаток нулю (A % 3 == 0).
   - Делит B на 3 и проверяет остаток (B % 3 == 0).
   - Делит C на 3 и проверяет остаток (C % 3 == 0).
   - Если 3 числа разделить без остатка то это выражение Истина.
   - Если хотя бы 1 дало остаток то Ложь.
6. Вывести результат расчётов в текст:
   - Если там 1, на экран выводится фраза: "Лунка является ИДЕАЛЬНОЙ".
   - Если там 0, срабатывает ветка else и выводится фраза: "Лунка НЕ подходит".
   - Если данные введены не корректно, то выводиться фраза "Ошибка ввода"
7. Конец

1. Успешный исход: идеальная лунка

Этот результат выводится, если абсолютно все три числа делятся на 3 без остатка (например: 3, 9, 30).
- Что вводит пользователь: 6 15 21
- Что выводит программа на экран:
Введите параметры кислотности почвы (A, B, C): 6 15 21

--- Результаты анализа ---
Итог: Лунка является ИДЕАЛЬНОЙ для посадки семян.

2. Успешный исход: лунка не подходит

Этот результат выводится, если хотя бы одно число не делится на 3 (остаток не равен нулю).
• Что вводит пользователь: 6 14 21 (число 14 дает остаток 2)
• Что выводит программа на экран:
Введите параметры кислотности почвы (A, B, C): 6 14 21

--- Результаты анализа ---
Итог: Лунка НЕ подходит для посадки семян.

3. Исход с ошибкой: некорректный ввод

Этот результат срабатывает благодаря блоку проверки корректности, если пользователь вместо чисел ввёл буквы, символы или забыл ввести какое-то число.
